### 2026-08-31 10:55｜CI 部署前置强制同步代码 + 回滚逻辑移至 CI 层

- **修改内容**：
  1. **CI 部署步骤第 0 步**：先 `git fetch origin main && git reset --hard origin/main`，强制同步远程代码，丢弃服务器上所有本地改动，避免"本地有未提交改动"导致部署失败
  2. **健康检查和回滚移至 CI 层**：部署脚本用 `--skip-healthcheck` 跳过内置健康检查，由 CI 负责健康检查和回滚（避免脚本自身被 git reset 修改导致执行异常）
  3. **回滚流程**：健康检查失败 → `git reset --hard $PREV_COMMIT` → 重新执行部署脚本 → 再次健康检查
- **修改原因**：服务器上有本地改动时部署脚本会直接 fail；且 git reset 会修改正在执行的脚本本身，导致行为不可预测。将代码同步和回滚逻辑放在 CI SSH 脚本中更稳定
- **影响范围**：`.github/workflows/cicd.yml`（部署步骤重写）、`scripts/deploy/deploy_update.sh`（保留 healthcheck/rollback 函数供手动使用）
