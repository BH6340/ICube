# 代码链接格式速查

## 链接写法

在 wiki 文档中，用标准 Markdown 链接指向后端代码：

```markdown
<!-- 行范围 -->
[用户认证逻辑](/code/cube_api/apps/accounts/views.py#L45-L80)

<!-- 单行 -->
[APIResponse 定义](/code/cube_api/utils/common_response.py#L12)

<!-- 整个文件 -->
[services.py 全文](/code/cube_api/apps/forum/services.py)
```

## 路径规则

- 路径以 `/code/` 开头，后接 `cube_api/` 内的相对路径
- `#L行号` 或 `#L起始-L结束` 指定高亮行
- 不带 `#L` 则展示整个文件

## 交互说明

| 操作 | 效果 |
|------|------|
| 点击代码链接 | 右侧面板滑出，展示代码 + 高亮指定行 |
| 点击不同链接 | 新开 Tab，可切换查看 |
| 点击 Tab 标题 | 切换到该文件 |
| 点击 Tab 上的 × | 关闭该 Tab |
| 点击面板右上角 « | 折叠面板（Tab 数据保留） |
| 折叠后点击代码链接 | 面板重新展开，展示对应文件 |
| 拖拽面板左边缘 | 调整面板宽度 |
| 关闭最后一个 Tab | 面板自动折叠 |
