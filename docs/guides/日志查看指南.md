# 日志查看指南

> 汇总本地、GitHub、服务器三端的日志查看地址和命令。

---

## 1. 本地开发日志

### 1.1 本地服务日志

`scripts/dev-local.ps1` 启动的服务日志输出到 `.dev-local/` 目录：

| 服务 | 日志文件 | 查看命令 |
|------|---------|---------|
| 后端 (Django) | `.dev-local/backend.out.log` | `Get-Content .dev-local\backend.out.log -Tail 50 -Wait` |
| Web 前端 (Vite) | `.dev-local/frontend.out.log` | `Get-Content .dev-local\frontend.out.log -Tail 50 -Wait` |
| 移动端 (Vite) | `.dev-local/app.out.log` | `Get-Content .dev-local\app.out.log -Tail 50 -Wait` |

### 1.2 自动拉取日志

| 日志 | 文件 | 查看命令 |
|------|------|---------|
| 自动拉取 | `.dev-local/auto-pull.log` | `Get-Content .dev-local\auto-pull.log -Tail 30` |

### 1.3 测试覆盖率报告

```powershell
# 运行测试并生成覆盖率报告

E:\software\python\python313\env\cube_api\Scripts\python.exe -m pytest --cov=cube_api/apps --cov=cube_api/utils --cov-report=term-missing

start htmlcov\index.html
```

## 2. GitHub CI/CD 日志

### 2.1 Actions 运行页面

| 查看内容 | 地址 |
|---------|------|
| 所有 workflow 运行 | https://github.com/BH6340/ICube/actions |
| 特定 run 详情 | https://github.com/BH6340/ICube/actions/runs/{run_id} |
| PR 检查结果 | PR 页面 → Checks 标签 |

### 2.2 命令行查看（gh CLI）

```bash
# 列出最近 10 次运行
gh run list --limit 10

# 查看某次运行的详情
gh run view {run_id}

# 查看失败 Job 的日志
gh run view {run_id} --log-failed

# 下载 artifact（覆盖率报告 / 部署日志）
gh run download {run_id} -n coverage-report
gh run download {run_id} -n deploy-log-{run_id}

# 实时查看正在运行的 workflow
gh run watch
```

### 2.3 Artifacts（CI 产出）

| Artifact 名称 | 内容 | 保留期 | 生成条件 |
|--------------|------|--------|---------|
| `coverage-report` | pytest 覆盖率 XML | 30 天 | 后端代码变更时 |
| `deploy-log-{run_id}` | 部署完整 stdout | 90 天 | 每次 main 部署（成功/失败均保存） |

下载方式：Actions run 页面 → Artifacts 区域下载，或用 `gh run download` 命令。

### 2.4 自动生成的 CHANGELOG

| 查看内容 | 地址 |
|---------|------|
| CHANGELOG.md | https://github.com/BH6340/ICube/blob/dev/CHANGELOG.md |
| 生成记录 | Actions → 对应 run → "生成 CHANGELOG" Job |

## 3. 服务器日志

### 3.1 Docker 容器日志

```bash
# 实时查看（-f 跟踪）
docker compose logs -f api              # 后端
docker compose logs -f nginx            # Nginx
docker compose logs -f front            # 前端
docker compose logs -f db               # MySQL
docker compose logs -f redis            # Redis

# 多服务同时查看
docker compose logs -f api nginx

# 查看最近 N 行
docker compose logs --tail 100 api

# 查看最近 5 分钟
docker compose logs --since 5m api

# 查看特定时间之后
docker compose logs --since "2026-09-01T00:00:00" api
```

### 3.2 部署相关日志

| 日志类型 | 位置 | 查看命令 |
|---------|------|---------|
| 部署完整输出 | GitHub Artifact（90 天） | `gh run download {run_id} -n deploy-log-{run_id}` |
| 本地改动备份 | `/tmp/local_changes_*.patch` | `ls -lt /tmp/local_changes_*.patch` |
| 数据库备份（迁移时） | `/tmp/icube_db_backup_*.sql` | `ls -lt /tmp/icube_db_backup_*.sql` |
| 异步备份输出 | `/tmp/backup_deploy.log` | `cat /tmp/backup_deploy.log` |

### 3.3 定时备份日志

| 日志 | 位置 | 查看命令 |
|------|------|---------|
| cron 备份日志 | `/home/bh/ICube/logs/server-backup-cron.log` | `tail -100 /home/bh/ICube/logs/server-backup-cron.log` |
| 单次备份输出 | 脚本 stdout（cron 重定向到上方文件） | 同上 |

### 3.4 Nginx 访问/错误日志

容器内日志，通过 `docker compose exec` 查看：

```bash
# 访问日志（最近 50 行）
docker compose exec nginx tail -50 /var/log/nginx/access.log

# 错误日志（实时跟踪）
docker compose exec nginx tail -f /var/log/nginx/error.log

# 搜索特定状态码（如 500）
docker compose exec nginx grep " 500 " /var/log/nginx/access.log | tail -20

# 搜索特定路径
docker compose exec nginx grep "/api/" /var/log/nginx/access.log | tail -20
```

### 3.5 服务状态检查

```bash
# 容器状态一览
docker compose ps

# 健康检查
curl -s -o /dev/null -w "%{http_code}" http://localhost/
curl -s -o /dev/null -w "%{http_code}" http://localhost/api/home/banners/

# 磁盘空间（排查日志/备份占满磁盘）
df -h

# /tmp 下备份文件大小
du -sh /tmp/icube_db_backup_*.sql 2>/dev/null
du -sh /tmp/local_changes_*.patch 2>/dev/null
```

## 4. 微信通知

部署成功/失败时通过 Server酱 推送微信通知，包含 commit 信息、时间和 Actions 链接，点击通知直接跳转对应 run 页面。

---

## 5. 快速排查清单

| 问题 | 第一步看什么 |
|------|------------|
| 部署失败 | 微信通知 → Actions run → `deploy-log` artifact |
| CI 测试失败 | Actions run → 后端 Job → 失败的 pytest 输出 |
| 线上 500 错误 | `docker compose logs --tail 100 api` → Nginx error log |
| 线上 502/504 | `docker compose ps` → `docker compose logs --tail 50 nginx` |
| 前端白屏 | `docker compose logs --tail 50 front` → Nginx error log |
| 数据库迁移失败 | `deploy-log` artifact → 搜索 "迁移" → `/tmp/icube_db_backup_*.sql` |
| 覆盖率下降 | `gh run download -n coverage-report` → 对比历史 |
| 备份失败 | `tail -100 /home/bh/ICube/logs/server-backup-cron.log` |
