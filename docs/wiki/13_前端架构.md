## 13. 前端架构（重点：与后端交互）

### 13.1 构建配置（[vite.config.js](/code/cube_front/vite.config.js)）

**双 Proxy**（dev 和 preview 完全镜像，均监听 `0.0.0.0:5173`）：

- `/api` → `http://127.0.0.1:8000`，`changeOrigin: true`
- `/media` → `http://127.0.0.1:8000`，`changeOrigin: true`

**自动导入**：

```js
AutoImport({ resolvers: [ElementPlusResolver()], imports: ['vue', 'vue-router', 'pinia'] })
Components({ resolvers: [ElementPlusResolver()] })
```

对应约定：业务代码无需 `import { ref } from 'vue'` 或手动注册 EP 组件。

**别名**：`'@'` → `./src`。

### 13.2 应用入口（[main.js](/code/cube_front/src/main.js) + [App.vue](/code/cube_front/src/App.vue)）

挂载流程：`createApp(App)` → 注册 EP 图标 → `use(createPinia())` → `use(ElementPlus)` → `use(router)` → 注册全局 errorHandler → `mount('#app')`。

App.vue 用 `ErrorBoundary` 包裹 `router-view`，捕获独立路由（登录/注册/找回密码）的渲染错误；`HomeView.vue` 的子路由也包一层 `ErrorBoundary`，确保主布局内组件崩溃不影响 Header/Footer。错误边界基于 `onErrorCaptured` + `return false` 阻止冒泡，显示 fallback 卡片（重试 + 返回首页 + 折叠错误详情），与 `RouteErrorState`（仅覆盖懒加载 chunk 失败）职责互补。

### 13.3 HTTP 请求层（[request.js](/code/cube_front/src/http/request.js)）— 重点

**axios 实例**：

- `baseURL: ''`（**空字符串**，`/api` 前缀在每个 api 模块的 `url` 字段中硬编码）
- `timeout: 5000`

**请求拦截器**（[L37-L46](/code/cube_front/src/http/request.js#L37-L46)）：

```js
const token = localStorage.getItem('token')
if (token) config.headers['Authorization'] = `Token ${token}`
```

- **直接从 localStorage 取 Token**，未通过 user store（与 store 共享 key 但绕过 Pinia）
- Token 前缀 `Token`（与后端 `CachedJWTAuthentication` 约定一致，非 `Bearer`）

**响应拦截器**（[L56-L81](/code/cube_front/src/http/request.js#L56-L81)）：

- 成功：`res.code === 100` → `return res`（完整响应体，含 code/msg/data）
- 业务失败：`res.code !== 100` → `ElMessage.error(res.msg || '请求服务器异常,请联系管理员')` + `Promise.reject(new Error(res.msg))`
- HTTP 错误：取 `error.response?.data?.msg`，同样 ElMessage + reject
- ⚠️ **未发现 401 自动跳转登录**，登录态过期依赖组件层 catch

### 13.5 状态管理（Pinia stores）

#### user store（[stores/user.js](/code/cube_front/src/stores/user.js)）

**state**（4 个 ref，初始化时全部从 localStorage 读取）：token / username / bio / image

**actions**：

- `setInfo(data)`：登录后整体写入 4 字段 + 同步 localStorage
- `updateInfo(data)`：局部更新，按字段 `undefined` 判断逐项写
- `clearInfo()`：清空 + `localStorage.clear()`

**持久化**：手动 `localStorage.setItem`，未用 pinia-persistedstate。

⚠️ store 未封装 `login/logout/getUserInfo` action，登录/登出逻辑分散在组件层（Header.vue 直接调 api + store 方法）。

#### cart store（[stores/cart.js](/code/cube_front/src/stores/cart.js)）

**非传统购物车数据 store**，而是**轻量版本号刷新机制**：

- `cartVersion = ref(0)`（模块级，全局共享）
- `bumpCartVersion()`：`cartVersion.value++`
- Header.vue 通过 `watch(cartVersion, loadCartCount)` 自动重新拉取购物车数量
- 购物车真实数据每次从后端 `getCart()` 拉取，前端不缓存

#### menu store（[stores/menu.js](/code/cube_front/src/stores/menu.js)）

- state：`allMenus` / `isLoaded`
- getters：`mainMenus`（category==='main'）/ `profileMenus`（category==='profile'）
- `fetchMenus()`：调 `getMenusApi()`，已加载时直接 return

#### routeLoading store（[stores/routeLoading.js](/code/cube_front/src/stores/routeLoading.js)）

路由加载状态管理，驱动顶部进度条和 chunk 加载失败兜底：

- state：`isLoading` / `currentPath` / `failedPath`
- `start(path)`：标记加载中，记录目标路径
- `finish()`：标记加载完成
- `fail(path)`：标记加载失败，触发 `RouteErrorState` 兜底组件

### 13.7 智能魔方组件与工具

#### Cube3D.vue（[components/cube/Cube3D.vue](/code/cube_front/src/components/cube/Cube3D.vue)）

Three.js 3x3 魔方 3D 渲染组件，支持转动动画和陀螺仪姿态跟随。

- **双层架构**：`outerGroup`（姿态层）+ `cubeGroup`（层转动层）解耦
- **转动队列**：TWEEN.js 动画 + requestAnimationFrame 按需渲染
- **暴露方法**：`rotate` / `rotateSequence` / `reset` / `clearQueue` / `setColorScheme` / `setAttitude` / `setInitialPose` / `resetAttitude`
- **性能优化**：共享 geometry/material、预分配临时对象、按需渲染

#### CubeNet.vue（[components/cube/CubeNet.vue](/code/cube_front/src/components/cube/CubeNet.vue)）

2D 魔方展开图组件，接收打乱序列 prop，使用 `cube-state.js` 计算状态后渲染 U/L/F/R/B/D 六面 3×3 网格。

#### SmartCubeView.vue（[views/SmartCubeView.vue](/code/cube_front/src/views/SmartCubeView.vue)）

智能魔方主页面，左侧 3D 渲染 + 右侧控制面板（连接/计时/持握方向/转动序列/调试日志）。页面加载时调 `tryAutoReconnect()` 尝试自动重连上次设备。

#### TimerView.vue（[views/TimerView.vue](/code/cube_front/src/views/TimerView.vue)）

计时器页面，支持手动/智能模式切换。智能模式包含 BLE 连接、打乱序列、复原进度，复用 SmartCubeView 的 BLE 单例和计时器逻辑。

#### gan-ble.js（[utils/gan-ble.js](/code/cube_front/src/utils/gan-ble.js)）

GAN Gen4 BLE 协议客户端，封装 Web Bluetooth API 连接、AES-128-CBC 加解密、协议事件解析（MOVE/GYRO/FACELETS/BATTERY 等）。单例模式，页面切换不中断连接。详见 [18_智能魔方功能实现详解](./18_智能魔方功能实现详解.md)。

#### cube-timer.js（[utils/cube-timer.js](/code/cube_front/src/utils/cube-timer.js)）

计时器状态机，管理 IDLE → SCRAMBLING → OBSERVATION → SOLVING → SOLVED 状态流转，支持 WCA 风格打乱生成、标准/不计时模式、打乱进度与错误处理。

#### cube-orientation.js（[utils/cube-orientation.js](/code/cube_front/src/utils/cube-orientation.js)）

持握方向检测与转体识别，支持陀螺仪模式（自动检测顶面）和经典模式（6 种预设），MOVE 重映射（`remapMove`），转体检测参数（累积 40°、帧间 5°、稳定 250ms）。

#### cube-state.js（[utils/cube-state.js](/code/cube_front/src/utils/cube-state.js)）

3x3 魔方 2D 状态模拟，6 面 × 9 贴纸，支持 R/L/U/D/F/B 顺时针/逆/180° 记号，供 CubeNet.vue 使用。
